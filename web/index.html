About this demo

CareScribe Live demonstrates browser-based documentation support. Live transcription depends on browser support and may use the browser vendor’s speech service. The safe simulation contains fictional, non-identifying sample content.

No AWS service or clinical system is connected. Data remains in local browser storage until you delete it.
