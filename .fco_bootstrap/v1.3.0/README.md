# FCO/FCG Universal Project Bootstrap v1.1.0

## Core purpose

Prepare projects for both:

1. executable reproducibility; and
2. claim-specific model credibility.

Reproducibility is a mandatory entry gate, not proof of biological validity,
predictive validity, safety, or fitness for a decision.

## Control-plane roles

- GettingScienceDone: governance, task decomposition, skill expansion, and MSM gates.
- Ollarma: bounded deterministic local execution and receipts.
- Antigence: Anticube admission, anomaly, safety, and policy enforcement.
- FCO/FCG: independent custody and evidence graph.
- BioSimulations: executable biomodel standards and reproduction target.
